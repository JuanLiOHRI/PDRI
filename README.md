# PD-RISK Index: Open data

This repo contains code to generate results in the manuscript entitled [*"PD-RISK Index: Piloting an unsupervised toolkit to identify adults with Parkinson disease"*](https://www.medrxiv.org/content/10.64898/2026.04.30.26352172v2)

------------------------------------------------------------------------

## Introduction

Due to data deidentification requirements, some variables, especially responses to the PD-RISK questionnaire, cannot be shared within an **open-access data set** (link to be updated). However, interested researchers could obtain access to the full dataset by contacting the corresponding authors and through a data use agreement.

This branch contains code for the restricted analysis using the **open-access data set**.

For individuals have access to the **full dataset**, please go to the **full-analysis branch**.

------------------------------------------------------------------------

## Requirements

The package `renv` is used for package management, see the `renv` folder and the lock file `renv.lock`. In the R session, run:

``` r
# 1. Restore packages (first time only)
renv::restore()
```

## Rmd and qmd files

This repo contains three main files, which need to be run in this specific order:

1.  `1_PDRI_scores.Rmd`: Generating versions of the PD-RISK questionnaire scores, UPSIT scores, simplified smell test (NeuroScent) scores, and the corresponding summary scores ('PD-RISK Indices').

- **Requires:**
  - **`Data/PDRI_curated_open.csv`: NOT included in this repo, link for open-access data to be updated**;
  - `Worksheets/PDRI_variables.csv`
  - `Worksheets/Olfactory_UPSIT_neuroscent_key.csv`
  - `Worksheets/UPSIT norm.csv`
- **Outputs:**
  - `Data/Code generated/Two_step_combine_betas.csv`
  - `Data/Code generated/PDRI_curated_scores.csv`

2.  `2_MANU_tables.qmd`: Generating Tables and Supplementary Tables.

- **Requires:**
  - `R/util.R`;
  - `Data/Code generated/PDRI_curated_scores.csv`
  - `Worksheets/PDRI_variables.csv`
  - `Worksheets/PDRI_variable_details.csv`
- **Tables affected by data de-identification requirement:**
  - Table 1: continuous age and disease duration were removed from the open-access dataset, thus Table 1 only contains sample size within each diagnostic group and sex. Further, diagnoses were grouped as "PD" or "OND", detailed diagnoses were also removed due to small cell size.
  - Supplementary Tables 1,2,4: since responses to almost all PD-RISK questionnaire were removed from the open-access dataset, univariate analyses could not be performed.

3.  `3_MANU_figures.qmd`: Generating Figures and Supplementary Figures.

- **Requires:**
  - `R/util.R`;
  - `Data/Code generated/PDRI_curated_scores.csv`
  - `Worksheets/PDRI_variables.csv`
  - `Worksheets/PDRI_variable_details.csv`
  - `Worksheets/diagnosis colors.csv`
- **Figures affected by data de-identification requirement:**
  - Figure 4, Supplementary Figure 8: since disease duration was removed from the open-access dataset.
  - Supplementary Figure 10: since detailed responses to race/ethnicity was removed from the open-access dataset.

## The `Data` folder

There is no data file within the `Data` folder in this repo, please access the data using this link (to be updated).

There is one sub-folder called `Code generated`, which will be used to store intermediate results generated by `1_PDRI_scores.Rmd`, also empty.

## The `Worksheets` folder

- Variable metadata:
  - `PDRI_variables.csv`
  - `PDRI_variable_details.csv`.
- Other supporting documents:
  - `Olfactory_UPSIT_neuroscent_key.csv`: answer key of the two smell tests
  - `UPSIT norm.csv`: UPSIT norm used to transform raw UPSIT score into age- and sex-adjusted percentiles
  - `diagnosis colors.csv`: data point colors

## The `R` folder

- `util.R`: function for ROC/AUC analysis
